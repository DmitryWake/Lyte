### Как получены файлы в модуле

Исходники — 512×512 PNG (чёрный штрих на прозрачном) в бандле дизайна:
`design/v2/_ds/lyte-design-system-4a58ed82-d30c-4b92-8a56-e55130ee91b0/assets/icons/exercises/`.
Рисунок не менялся, менялся только размер: глиф рисуется максимум ~30dp (круг-маркер 52dp), а
Compose на Android умеет только билинейную фильтрацию, поэтому даунскейл в шесть с лишним раз
съедал тонкий штрих.

Ресайз до 256×256 сделан **по альфа-каналу**, а не по RGBA: цвет исходника везде один и тот же
чёрный, поэтому интерполяция цвета не нужна, а у трёх палитровых файлов она дала бы ореол на краях.

```python
from PIL import Image
alpha = Image.open(src).convert("RGBA").getchannel("A").resize((256, 256), Image.LANCZOS)
out = Image.new("RGBA", (256, 256), (0, 0, 0, 0))
out.putalpha(alpha)
out.save(dst, "PNG", optimize=True)
```

Имена файлов — `ic_exercise_<ключ>.png`, ключи и порядок совпадают с `EXERCISE_ICON_ORDER`
дизайн-системы (`_ds_bundle.js`).
