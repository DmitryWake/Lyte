# Lyte

Приложение для отслеживания тренировок (Android и iOS): программы тренировок,
трекинг подходов и история занятий.

Все данные хранятся локально на устройстве — приложение не собирает и не передаёт
никакой информации.

Издатель — физическое лицо, Николаевский Дмитрий Александрович.
