# Дизайн Lyte v2

Хендофф-бандл из Claude Design (claude.ai/design) — источник правды по редизайну.
План перехода приложения на эту систему — [roadmap/design-v2/TASKS.md](../../roadmap/design-v2/TASKS.md).

Файлы **не редактируются вручную**: это выгрузка дизайн-тула. Новая итерация дизайна приезжает
следующим бандлом (`design/v2.1/` и т.д.), а не правкой этих файлов.

## Что где

| Путь | Что это |
|---|---|
| `LyteScreen.dc.html` | **Все экраны MVP.** Строки 30–520 — разметка, 522–1461 — данные, тона, логика прототипа |
| `Lyte - Экраны v2.dc.html` | Канвас: список кадров с подписями (строки 59–109) |
| `Lyte - Прототип.dc.html` | Обёртка для интерактивного прохода по прототипу |
| `_ds/<id>/readme.md` | Принципы системы: тон, цвет, иконография, что и почему изменилось в v2 |
| `_ds/<id>/_ds_bundle.js` | Исходники всех компонентов (читаемый JS с комментариями-обоснованиями) |
| `_ds/<id>/tokens/` | `colors` · `accents` · `typography` · `spacing` (там же shape, elevation, motion) · `fonts` |
| `_ds/<id>/assets/icons/exercises/` | 10 пиктограмм движений, 512×512 PNG |
| `support.js`, `dark-scope.css`, `styles.css` | Рантайм и стили канваса — нужны, чтобы html открывался в браузере |

`<id>` — `lyte-design-system-4a58ed82-d30c-4b92-8a56-e55130ee91b0`. Имя длинное и неудобное, но на него
ссылаются `<link>`/`<script>` внутри html, поэтому оставлено как есть.

## Чего здесь нет и почему

- **Шрифты** (`_ds/<id>/assets/fonts/`, 568 КБ) — это те же самые файлы, что уже лежат в
  `core/core-design/src/commonMain/composeResources/font/`. Дубликат в git не нужен.
  Следствие: при открытии html в браузере текст рисуется системным шрифтом. Если нужен точный рендер —
  скопируйте 5 `.ttf` из `core-design` в `_ds/<id>/assets/fonts/`, пути уже прописаны в `tokens/fonts.css`.
- **`uploads/`** — архив предыдущего хендоффа (v1) на 900 КБ. Актуальную сводку «что изменилось между
  v1 и v2» даёт таблица в `_ds/<id>/readme.md`.
- **`_ds_manifest.json`, `_adherence.oxlintrc.json`, `.thumbnail`** — служебные метаданные дизайн-тула,
  для реализации бесполезны. Список компонентов есть в шапке `_ds_bundle.js`.

## Лицензии

Пиктограммы движений — Flaticon (автор Icongeek26), бесплатная лицензия **с обязательной атрибуцией**:
кредит должен быть виден пользователю приложения. Подробности и план — решение 2 в [roadmap/design-v2/TASKS.md](../../roadmap/design-v2/TASKS.md)
и задача RD-22. Шрифты Space Grotesk и Inter Tight — OFL (текст лицензии бандлится приложением:
`core/core-design/src/commonMain/composeResources/files/OFL.txt`).
